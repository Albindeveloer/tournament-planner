# Useful Commands (Auth Service)

Run these commands from the repository root unless noted otherwise.

## Install Dependencies

```bash
npm install
```

## Run Auth Service (dev)

```bash
npm run dev --workspace=@tournament-planner/auth-service
```

## Type Check

```bash
npm run typecheck --workspace=@tournament-planner/auth-service
```

## Build

```bash
npm run build --workspace=@tournament-planner/auth-service
```

## Start Built Service

```bash
npm run start --workspace=@tournament-planner/auth-service
```

## Run Tests

```bash
npm run test --workspace=@tournament-planner/auth-service
```

## Run Test Watch Mode

```bash
npm run test-watch --workspace=@tournament-planner/auth-service
```

## Lint

```bash
npm run lint --workspace=@tournament-planner/auth-service
```

## Format / Format Check (repo-wide)

```bash
npm run format
npm run format:check
```

## Test PostgreSQL Connection Script

```bash
npm exec --workspace=@tournament-planner/auth-service tsx src/infrastructure/database/test-connection.ts
```
